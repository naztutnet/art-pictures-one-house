# Art Pictures — One House

Инициативный интерактивный прототип единого цифрового дома Art Pictures Studio, Vision и Motion.

Это исследовательская концепция для обсуждения с командой Art Pictures, а не утверждённый редизайн и не официальный сайт.

## Что реализовано

- единая бренд-архитектура для Studio, Vision и Motion;
- переключение между тремя направлениями;
- фильтруемая подборка проектов;
- демонстрационный сценарий общего showreel;
- блок корпоративного доверия;
- адаптивная мобильная версия.
