# Art Pictures — Redesign Prototype

Инициативный прототип редизайна сайта Art Pictures Studio, Vision и Motion.

Это исследовательская версия для обсуждения с командой Art Pictures, а не утверждённый редизайн и не официальный сайт.

## Что реализовано

- навигация между Studio, Vision и Motion
- фильтруемая подборка проектов
- демонстрационный сценарий showreel
- блок о компании и новости
- адаптивная мобильная версия
- корпоративная палитра Art Pictures

## Публикация

GitHub Pages разворачивается автоматически из ветки `main` через GitHub Actions.
